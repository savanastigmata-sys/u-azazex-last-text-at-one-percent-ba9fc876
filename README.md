The last text message a phone sends at one percent battery, in the dying phone's own voice: "1%. Screen time today: 9 hours. I didn't run out of battery - you used me up. Tell the charger it was too late. It always is."

`main.py` writes that one line (125 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```
